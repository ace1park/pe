# 자동 점검 (tests)

앱(`data`·`js`·`css`)을 고친 뒤 화면과 버튼이 그대로 잘 작동하는지 컴퓨터에서 자동으로 확인하는 파일들입니다. 휴대폰에서 앱을 쓰는 데에는 필요 없습니다.

## 점검 종류

| 파일 | 확인하는 것 |
|---|---|
| `data.test.js` | 모든 종목·차시·활동(2,100여 개)을 훑어 활동 4개·방법 단계 수·지도 포인트·쉽게/어렵게·대형 그림·그림 틀 이름·넣지 않기로 한 말 (1분, 자료를 고친 뒤 가장 먼저) |
| `func.test.js` | 버튼·타이머·+1분·점수판·정지 신호·팀 나누기·감정 기록·왕관·리그표·게임 카드·기록 유지·정지 신호 위치·키보드 단축키 ·기본 자료(data/links.js) 등 50가지 |
| `classmode.test.js` | 수업 중 모드: 켜기·큰 타이머·+1분·팀 보기·대형 그림·난이도·정지·점수판·인원 바꾸기·왕관·1분 알림·끄기 |
| `screens.test.js` | 302차시 × 6단계 화면을 모두 열어 오류, 대형 그림 누락, 글자 넘침 |
| `people.test.js` | 소규모 6~14명·일반학급 15~24명·합반 25~50명마다 모든 화면·점수판·팀 나누기, 모둠 인원 합계, 결석 1~3명 반영 |
| `text.test.js` | 화면 너비별 글자 잘림, 화면 밖 넘침, 한 줄이어야 할 곳의 줄바뀜 |
| `clicks.test.js` | 여러 화면의 모든 버튼과 링크를 하나씩 눌러 오류 |
| `newunit.test.js` | 견본 새 종목 파일을 켜서 홈·학년 보기·단원·차시 6단계·수업 중 모드·오류 알림 |
| `nodes.test.js` | 단계마다 차시 원이 한 줄에 다 들어가는지 (세로 320~768px, 가로 1280px) |
| `wrap.test.js` | 짧은 이름표·버튼 글자와 아이콘이 두 줄로 갈라지지 않는지 (320·360·390·768px, 안내사항·홈·단원·차시 화면 전체) |
| `find.test.js` | 활동 찾기: 낱말·장소·조건으로 줄어드는지, 모두 지우기, 결과를 누르면 그 활동 단계로, 화면 밖 넘침 (320·390·1280px) |
| `record.test.js` | 기록 내보내기 파일(영어 이름)·가져오기로 되살리기·다른 파일 거절, 종목별 차시 공 모양, 판 번호 표시 |
| `home.test.js` | 모든 화면을 맨 아래까지 내려도 위쪽 홈 버튼이 보이는지 (세로·가로 휴대폰, 컴퓨터) |
| `run-all.js` | 위 점검을 기기·너비별로 모두 실행하고 결과 요약 |

## 실행 방법 (컴퓨터)

1. [Node.js](https://nodejs.org) LTS 설치
2. 이 `tests` 폴더에서 터미널을 열고:

```bash
npm install
npx playwright install chromium
npm test            # 전체 점검 (10~20분)
npm run test:quick  # 빠른 점검 (2~3분)
```

하나만 돌릴 때:

```bash
DEV="Galaxy S9+" node func.test.js
WIDTH=360 node screens.test.js
node text.test.js 360
```

기본으로 한 단계 위 폴더의 `index.html`을 엽니다. 올린 주소를 점검하려면 `PE_URL=https://아이디.github.io/저장소이름/ npm test`처럼 실행합니다.

## 참고

- 마지막 줄에 `통과` 또는 `실패`가 나오고, 실패하면 무엇이 문제인지 위에 적혀 나옵니다.
- 크롬(Chromium)으로 휴대폰 크기를 흉내 내는 점검입니다. 실제 아이폰 Safari 확인은 휴대폰으로 직접 열어 보세요.
- `text.test.js`의 '짧은 끝줄(orphan)'은 긴 설명 문단의 마지막 줄이 짧게 남은 것으로, 참고용이며 실패로 치지 않습니다.
