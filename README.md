# 내 손 안의 체육

초등 체육 수업을 **휴대폰 하나로** 안내하는 수업 도우미입니다. 전자칠판·TV·컴퓨터에서도 같은 주소로 열립니다.

- 12개 단원 459차시: 발로 하는 공놀이(3학년 20 · 4학년 20), 티볼(4학년 30), 티볼 심화(5~6학년 24 + 게임 카드 28), 배드민턴(3~6학년 48), 배구형 게임(3~6학년 48), 육상(3~6학년 92), 넷볼(5~6학년 20), 농구(5~6학년 20), 축구형 게임(5학년 14 · 6학년 14), 츄크볼(5~6학년 13), 플라잉 디스크(3~6학년 48), 플로어볼(3~6학년 48)
- 홈에서 두 갈래로 고름: **차근차근 배울까?**(단원으로 깊게 배우기) · **오늘 뭐하지?**(어느 날 꺼내 쓰는 40분 놀이 한 판 · 교실놀이 10가지)
- 차시마다 약속 → 연습1 → 게임1 → 연습2 → 게임2 → 돌아보기 (각 10분)
- **수업 중 모드**: 휴대폰을 힐끗 보고 진행하도록 지금 활동·큰 타이머·이렇게 해요·꿀팁·팀·다음 활동만 크게 (화면 꺼짐 방지, 1분 전 소리·진동)
- 타이머, 정지 신호(호루라기 소리), 점수판, 출석 번호로 팀 나누기(홀수 반 자동 처리)
- 일반학급 15~24명, 소규모 학급 6~14명, 합반 25~50명
- 결석·지각: 빠진 번호만 누르면 나머지 모둠은 그대로, 빈자리만 채움(옮긴 친구는 노란 테두리)
- 낱말 풀이: 활동마다 그 활동에 나온 경기 용어(바운더, 페이스오프, 골서클 등)를 쉬운 말로 풀어 보여 줌. 전체 목록은 안내사항 7번
- 경기장·공 수를 넣으면 동시에 할 경기 수와 판별 대기 순서를 알려 줌
- 연습·게임을 6인(3:3)·8인(4:4)·10인(5:5) 모둠으로 바꾸기
- 차시를 끝내면 성공 왕관, 활동마다 시범 사진·영상·유튜브 링크 넣기

## 아이폰에서 쓰기 (이 묶음이 아이폰용)

아이폰은 앱스토어 앱이 아닌 경우 **웹 주소로 연 페이지만** 앱처럼 설치할 수 있습니다. 받은 HTML 파일을 파일 앱·카카오톡에서 열면 버튼이 작동하지 않습니다. 그래서 이 묶음을 웹 주소에 올려 씁니다.

1. 이 묶음을 깃허브 Pages 등 https 주소에 올립니다. (아래 '올리는 방법')
2. 아이폰 **Safari**로 그 주소를 엽니다. (카카오톡 안의 브라우저가 아니라 Safari)
3. 아래쪽 공유 버튼(네모에 위 화살표) → **홈 화면에 추가** → **추가**
4. 홈 화면의 '내 손 안의 체육' 아이콘으로 엽니다. 시작 화면이 나오고 전체 화면 앱처럼 열립니다.
5. 한 번 열어 두면 체육관에서 인터넷이 없어도 열립니다.

알아 두기
- Safari에서 처음 열면 화면 아래에 '아이폰에서 앱처럼 쓰기' 안내가 나옵니다.
- 아이폰은 진동 기능이 없어서, 1분 전·10분 끝·정지 신호 때 화면 가장자리가 노랗게 깜빡입니다. 옆면 무음 스위치를 켜 두면 소리가 나지 않습니다.
- 홈 화면 앱과 Safari는 기록(도장·왕관·인원)을 따로 저장합니다. 한쪽으로만 쓰세요.

## 안드로이드에서 쓰기

- 위 주소를 **Chrome**으로 열면 '앱으로 설치하기' 안내가 나옵니다. **설치**를 누르면 홈 화면에 아이콘이 생깁니다. (⋮ → '앱 설치'도 됨)

## 인터넷 없는 교실·USB

- `내손안의체육_파일용.html` 한 파일에 앱 전체가 들어 있습니다. 컴퓨터·전자칠판에서 더블클릭하면 인터넷 없이 열립니다.
- 이 파일은 Claude에게 "파일용 HTML 새로 만들어 줘"라고 하면 만들어 줍니다(`tools/make_single.py`).

## 올리는 방법 (깃허브 Pages, 무료)

1. github.com에 로그인 → 오른쪽 위 **+** → **New repository** → 이름 예: `pe` → **Public** → **Create repository**
2. **uploading an existing file**을 누르고, 압축을 푼 폴더 안의 파일과 폴더를 모두 끌어다 놓기 → **Commit changes**
3. **Settings → Pages** → Branch를 **main / (root)**로 고르고 **Save**
4. 1~2분 뒤 `https://아이디.github.io/pe/` 로 열림

## 개인정보

- 학생 이름은 받지 않습니다. 팀은 출석 번호로만 나눕니다.
- 도장·왕관·인원·점수·넣은 사진과 영상은 **그 휴대폰(브라우저)에만** 저장되고 어디로도 보내지 않습니다.
- 학생이 나오는 사진·영상은 보호자 동의를 받은 것만 넣고, 얼굴은 최소로 나오게 합니다.

## 파일 구성

고칠 것이 어느 파일에 있는지는 **`수정하는_법.md`**에 정리되어 있습니다.

| 폴더·파일 | 내용 | 고칠 일 |
|---|---|---|
| `data/` | 단원·차시 글, 약속, 게임 카드, 기본 영상·사진 링크, 새 종목(`data/units/견본_새종목.js` 복사 + `list.js` 한 줄) | **여기를 고칩니다** |
| `media/` | 모든 기기에 보일 사진 | 사진 올릴 때 |
| `js/` | 프로그램(화면 만들기·타이머·소리 등). `js/gloss.js`는 낱말 풀이 표 | 거의 없음(낱말 더할 때 `gloss.js`) |
| `css/app.css` | 색·글자 크기·배치 | 거의 없음 |
| `index.html` | 앱의 뼈대(파일을 불러오는 순서) | 거의 없음 |
| `sw.js` | 인터넷 없이 쓰게 해 주는 서비스 워커 | 새 파일을 만들 때만 |
| `manifest.webmanifest`, `icons/` | 홈 화면 아이콘과 앱 이름, 아이폰 시작 화면 | 없음 |
| `fonts/` | 글꼴(Black Han Sans, Gothic A1 · SIL Open Font License 1.1) | 없음 |
| `tests/` | 자동 점검 (`tests/README.md`) | 없음 |
| `tools/` | 파일용 HTML 만들기 도구 | 없음 |
